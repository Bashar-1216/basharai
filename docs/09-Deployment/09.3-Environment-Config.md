## 1. Secrets Management Strategy

تعتمد حماية البيانات والمفاتيح الحساسة في منصة bashar.ai على قواعد صارمة تمنع تسريب الرموز السرية أو تدوينها داخل المستودع العام (Hardcoding secrets):

- **حظر كامل لرفع الأسرار في Git:** يتم تسجيل كافة الملفات الحساسة (مثل `.env`, `.env.local`, `service-account.json`) داخل ملف `.gitignore` لمنع رفعها بالخطأ.
- **إدارة الأسرار عبر الحوسبة السحابية (Cloud Managed Env):**
  - في الاستضافة: يتم إدخال المتغيرات الحساسة يدوياً عبر واجهة التحكم الآمنة لـ **Vercel Console** و **Railway Environment Panel**.
  - يتم تشفير المتغيرات أثناء الحفظ وفي مسار النقل (Encrypted at rest & in transit).
- **مفاتيح الاتصال البيني (BFF Authentication):** نستخدم مفتاح ربط سري موحد `INTERNAL_API_KEY` لمنع استدعاء محرك FastAPI من خارج خادم Next.js BFF.

## 2. Frontend Environment Variables (Next.js)

المتغيرات اللازمة لتشغيل الواجهة الأمامية وإدارة مصادقة NextAuth.js:

- `NEXTAUTH_SECRET`: رمز التشفير السري لرموز جلسة JWT الخاصة بالمسؤول.
- `NEXTAUTH_URL`: الرابط الأساسي للموقع (`https://bashar.ai`).
- `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`: معرفات OAuth لحساب Google.
- `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET`: معرفات OAuth لحساب GitHub.
- `NEXT_PUBLIC_API_URL`: الرابط العام لخادم FastAPI (`https://api.bashar.ai/api/v1`).
- `INTERNAL_API_KEY`: المفتاح المشترك لتأمين الاتصال الداخلي مع خادم FastAPI.

---

## 3. Backend Environment Variables (FastAPI)

المتغيرات اللازمة لتشغيل خادم معالجة الذكاء الاصطناعي وقاعدة البيانات:

- `DATABASE_URL`: رابط الاتصال المؤمن بقاعدة بيانات PostgreSQL (مع pgvector).
- `REDIS_URL`: رابط الاتصال بالذاكرة المؤقتة Redis لإدارة معدلات الاستهلاك (Rate Limiting).
- `OPENAI_API_KEY`: مفتاح OpenAI للوصول للنماذج وتوليد التضمينات (Embeddings).
- `INTERNAL_API_KEY`: المفتاح المشترك لمطابقته مع طلبات Next.js BFF.

## 4. Environment Classifications Registry

توضح القائمة التالية نوع وتصنيف وأهمية المتغيرات البيئية لضمان سلامة الإدارة:

| Variable Name | Env Scope | Classification Level | Target Scope | Purpose |
|---------------|-----------|----------------------|--------------|---------|
| `NEXTAUTH_SECRET` | Frontend | 🔴 **Secret Key** | Staging / Prod | Encrypts Auth JWE tokens. |
| `DATABASE_URL` | Backend | 🔴 **Secret Key** | Staging / Prod | PostgreSQL credentials. |
| `OPENAI_API_KEY`| Backend | 🔴 **Secret Key** | Staging / Prod | Paid OpenAI API access. |
| `INTERNAL_API_KEY`| Both | 🔴 **Secret Key** | Staging / Prod | Validates BFF-to-FastAPI. |
| `NEXT_PUBLIC_API_URL`| Frontend | 🟢 **Public Config**| Staging / Prod | API base path for client. |
