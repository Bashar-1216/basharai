## 1. Automated SSL Provisioning (Let's Encrypt)

تأميناً لخصوصية بيانات الزوار والتزاماً بمعايير حماية المدونات والمحافظ المهنية الاحترافية، تُشفر كافة الاتصالات بين المتصفح والخوادم باستخدام شهادات **Let's Encrypt SSL (TLS 1.3)** المؤتمتة بالكامل:

- **Next.js Frontend (Vercel):** تقوم Vercel بإصدار شهادة SSL وتوجيهها وإدارتها تلقائياً وتجديدها كل 90 يوماً بشكل غير محسوس ودون الحاجة لأي تدخل بشري.
- **FastAPI Backend (Railway):** يقوم خادم Railway تلقائياً بإصدار شهادة SSL مخصصة للنطاق الفرعي `api.bashar.ai` فور ربطه وتأكيد ملكية DNS، وتجديدها خلف الكواليس.

## 2. Cloudflare TLS Encryption Settings (Full Strict)

لمنع هجمات التنصت (Man-in-the-Middle) وضمان تشفير كامل القناة حتى خلف الـ CDN:

- **وضع تشفير TLS (TLS Encryption Mode):** يتم تفعيل وضع **Full (Strict)** في لوحة Cloudflare.
- **آلية العمل:** يفحص Cloudflare صحة شهادة Let's Encrypt الصادرة من خوادم Vercel/Railway قبل السماح بنقل البيانات، مما يمنع استغلال الشهادات المزيفة أو منتهية الصلاحية.

## 3. HTTP Strict Transport Security (HSTS) Policy

لمنع المتصفحات من محاولة تحميل النسخة غير المشفرة (HTTP) وتوجيه كافة الطلبات قسراً إلى HTTPS، نرسل الرأس المعياري التالي مع كل استجابة من Next.js BFF أو خادم FastAPI:

```http
Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
```

- `max-age=63072000`: إجبار المتصفح على استخدام HTTPS فقط لمدة عامين متتاليين.
- `includeSubDomains`: سريان السياسة على كافة النطاقات الفرعية (مثل `api.bashar.ai`).
- `preload`: تسجيل النطاق في قائمة HSTS Preload للمتصفحات الشهيرة (Chrome, Safari, Firefox) ليتم التحميل الآمن فورياً دون انتظار أول استجابة.

## 4. TLS Protocol Version Enforcement

لحماية أمان الجلسات والتأكيد على حداثة النظام الأمني للمنصة:
- نمنع الاتصال بالبروتوكولات القديمة الضعيفة (TLS 1.0 و TLS 1.1) بالكامل.
- **الحد الأدنى المدعوم (Minimum TLS Version):** فرض بروتوكول **TLS 1.2** كحد أدنى للتوافق، مع تفضيل وتمرير بروتوكول **TLS 1.3** الأسرع والأكثر أماناً كخيار افتراضي لكافة المتصفحات الحديثة.
