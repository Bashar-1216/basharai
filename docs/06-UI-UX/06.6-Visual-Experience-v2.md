## 1. Visual Strategy: The Three-Stage Narrative | الاستراتيجية البصرية

لتأسيس واجهة متوازنة لا تسقط في فخ "مواقع الهبوط الاستعراضية" ولا تتطرف لتصبح لوحة تحكم داخلية جافة، نعتمد على **نموذج السرد الهندسي الراقي (Premium Engineering Narrative)** الذي يقود الزائر في رحلة تدريجية:

```
+-----------------------------------------------------------------+
| 1. EMOTION (20% Human)   --> Who am I? Can I build AI?          |
|                              Clean typographic Hero statement.  |
+-----------------------------------------------------------------+
                                │
                                ▼
+-----------------------------------------------------------------+
| 2. TRUST (40% Narrative) --> Can I ship? Can I own systems?      |
|                              Timeline & Case studies.           |
+-----------------------------------------------------------------+
                                │
                                ▼
+-----------------------------------------------------------------+
| 3. EVIDENCE (40% Evidence)--> Can I operate production systems?  |
|                              Developer Console & Metrics logs.  |
+-----------------------------------------------------------------+
```

### 2.2 Dual-Mode AI Chat Assistant: Simple vs. Developer View
واجهة المحادثة تبدأ نظيفة وبسيطة لتناسب مسؤولي التوظيف العاديين، مع إتاحة زر **`[ Developer View ]`** للمهندسين ومدراء التقنية لعرض التفاصيل الفنية الحية:

#### وضع المحادثة المبسط (Simple View):
```
+-------------------------------------------------------------------------+
| 🤖 AI Assistant                                        [Developer View] |
| ----------------------------------------------------------------------- |
| Visitor: Tell me about Bashar's NLP work.                               |
| Assistant: Bashar built transformer pipelines at Grammarly...          |
| ----------------------------------------------------------------------- |
| > Type a question...                                                [>] |
+-------------------------------------------------------------------------+
```

#### وضع المطور النشط (Developer View):
عند التفعيل، تنقسم الشاشة لعرض تفاصيل RAG Telemetry:
```
+-----------------------------------------+-------------------------------+
| 🤖 AI Assistant        [Developer View] | ⚙️ RAG METRICS                 |
| --------------------------------------- | ----------------------------- |
| Visitor: Tell me about Bashar's NLP...  | Model: gpt-4o-mini            |
| Assistant: Bashar built transformer...  | Latency: 420ms | Cost: $0.003 |
|                                         | Sources:                      |
|                                         | - docs/experience/nlp.md      |
| --------------------------------------- | Tokens: 480 In / 120 Out      |
| > Type a question...                [>] | Confidence: 94.2%             |
+-----------------------------------------+-------------------------------+
```

### 2.3 Experience & Projects: Engineering Stories
نصمم الصفحات لتجيب على أسئلة محددة تهم مديري التوظيف:

- **الخبرة المهنية (Can I ship?):** تخطيط نظيف يشبه سير العمل المهني الراقي، مع إبراز تواريخ ومناطق الأثر المالي والهندسي (ex-Amazon, ex-Grammarly).
- **دراسات الحالة للمشاريع (Can I own systems?):** سرد هندسي متكامل مقسم لفقرات واضحة:
  1. **المشكلة والقرار (The Challenge & Decision)**
  2. **الهيكل المعماري (The Architecture)**
  3. **التضحيات والخيارات البديلة (Trade-offs & Alternatives)**
  4. **الدروس المستفادة (Lessons Learned & Key Metrics)**

## 3. Background Layers & Noise Texture | لوحة الطبقات والأنسجة

لمنع المظهر المسطح الجاف (Flat Layout)، نبني خلفية تحتوي على عمق طباعي دافئ:

- **الطبقة الأساسية (Base Layer):** لون الرمادي الكحلي الداكن `#0A0F1C`.
- **النسيج الرقمي (Digital Noise Texture):** نسيج حبيبي خفيف جداً (Opacity 2% Noise SVG) مغطى بالخلفية ليعطي ملمس الورق الطبيعي.
- **حدود التقسيم (Paper Borders):** حدود رقيقة بلون `rgba(148, 163, 184, 0.15)` مع ظل أزرق دافئ وناعم جداً `0 8px 40px rgba(37, 99, 235, 0.08)` خلف الألواح والفقرات الأساسية للإيحاء بالبروز البصري الخفيف.
