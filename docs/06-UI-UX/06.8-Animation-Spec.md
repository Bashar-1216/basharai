## 1. Animation Principles

تُعد الحركة والتحريكات البصرية أداة أساسية لإحداث **انطباع بصري مميز (Wow Factor)** في المنصة. لا نستخدم الرسوم لمجرد الزينة، بل لتسهيل الإدراك، إرشاد عين القارئ، وتوفير استجابة حسية تعزز من متعة استخدام الموقع.

### المبادئ العامة للحركة:
- **الرشاقة والسرعة (Swift & Snappy):** لا نستخدم الحركات البطيئة المملة. تتراوح مدة معظم التحريكات بين **150ms إلى 300ms** لتوفير تجربة سريعة وخفيفة.
- **التوازن والنعومة (Physics-based Spring):** نبتعد عن الحركات الخطية الجافة (Linear easing) ونعتمد على قوانين حركة النوابض الطبيعية (Spring physics) لإنتاج ارتدادات ناعمة ومرنة ومطابقة للواقع البصري.

## 2. Animation Framework (Framer Motion)

تم اختيار مكتبة **Framer Motion** لإدارة التحريكات في الواجهة الأمامية Next.js.

### ميزات Framer Motion:
- تكامل ممتاز مع React ومكونات الحالة.
- دعم مدمج لحركة تغيير المكونات في الشجرة البرمجية (`AnimatePresence`).
- حركات ذكية تعتمد على تسارع العتاد وتتفادى استهلاك طاقة المعالجة المركزية (GPU Accelerated).

## 3. Page Transitions Spec | انتقالات الصفحات

عند تنقل المستخدم بين مسارات الموقع (مثال: من السيرة الذاتية إلى المشاريع)، يتم تشغيل انتقال انزلاقي ناعم يتلاشى تدريجياً:

```typescript
// Shared Page transition configuration
export const pageTransitionVariants = {
  initial: {
    opacity: 0,
    y: 10, // Small vertical offset for slide-up effect
  },
  animate: {
    opacity: 1,
    y: 0,
    transition: {
      duration: 0.3,
      ease: [0.25, 0.1, 0.25, 1.0], // Snappy cubic-bezier
    },
  },
  exit: {
    opacity: 0,
    y: -10,
    transition: {
      duration: 0.2,
    },
  },
};
```

## 4. Micro-interactions & Hover States | التفاعلات الصغيرة

- **حالة التحويم للأزرار (Button Hover):**
  - تمدد طفيف للزر بنسبة 2% (`scale: 1.02`) مع توهج نيون ناعم للحدود الخارجية (glow effect) يزيد من التباين البصري للزر.
- **ظهور كروت المشاريع (Scroll Reveal):**
  - عند تمرير الصفحة لأسفل ودخول كروت المشاريع إلى شاشة العرض (Viewport)، تنزلق الكروت للأعلى برفق وبمعدل تتابع تدريجي (Stagger effect) بمقدار **50ms** بين كل كرت وتاليها، مما يمنح إحساساً بالتنظيم والترتيب.

## 5. RAG Assistant Bubble Animations

يتم تحريك فقاعات رسائل المساعد الذكي RAG (Epic E1) لتسهيل قراءة الحوار المتدفق:

- **ظهور الرسالة الجديدة:**
  - تنبثق الفقاعة الجديدة من الأسفل مع تلاشي ناعم (`scale: 0.95 -> 1.0`, `opacity: 0 -> 1`) في زمن قدره **200ms** مع ارتداد نابض طفيف (`bounce: 0.25`).
- **مؤشر البث (SSE Streaming Cursor):**
  - يومض مؤشر البث الفرعي (cursor) بنبضات متكررة (`opacity: 1 -> 0 -> 1`) كل **800ms** لمحاكاة عملية الكتابة الآلية الحية أمام القارئ.

## 6. Accessibility & Reduced Motion

نحترم رغبة وتفضيلات زوار الموقع الذين يعانون من مشاكل حساسية الحركة أو الصداع النصفي:
- نقوم بقراءة إعدادات نظام تشغيل الزائر المخصصة لتقليل الحركة (**`prefers-reduced-motion`**).
- في حال تفعيلها، نقوم بإيقاف جميع التحريكات والاهتزازات والانتقالات الانزلاقية تلقائياً برمجياً ونستبدلها بـ **تلاشٍ فوري وبسيط للمحتوى (Instant Fade)** دون أي إزاحة عمودية أو تمدد.

## 7. Performance Constraints (Layout Thrashing Prevention)

لحماية أداء الموقع ومنع حدوث انخفاض في معدل الإطارات (Frame rate drops):
- **قاعدة صارمة:** يُمنع تحريك الخصائص التي تسبب إعادة حساب أبعاد الصفحة (Layout properties) مثل `width` أو `height` أو `top` أو `margin`.
- **البديل المعتمد:** نعتمد كلياً على تحريك الخصائص المدعومة بمسرع الرسوميات (Composite properties) مثل **`transform`** (للإزاحة والتحجيم والدوران) و **`opacity`** (للتلاشي والوضوح) لضمان ثبات معدل الإطارات عند **60fps** دائمًا.
