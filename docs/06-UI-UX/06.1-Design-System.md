## 1. Visual Principles

يهدف نظام التصميم في منصة bashar.ai إلى إحداث **انطباع بصري مبهر (Wow Factor)** من أول نظرة، بما يعكس الهوية الاحترافية لمهندس ذكاء اصطناعي لديه خبرة في كبرى شركات التقنية العالمية (Amazon & Grammarly). 

### المبادئ البصرية:
- **المظهر الرقمي المتقدم (Glassmorphism & Neon Accent):** نستخدم خلفيات شبه شفافة مع تشويه ضبابي (backdrop-blur) مع حدود نيونية خفيفة لإعطاء عمق وتأثير ثلاثي الأبعاد للمكونات.
- **تفضيل المظهر الداكن (Dark Mode Native):** يتم تحميل الموقع بالوضع الداكن كوضع افتراضي وتفضيل لجمهور المطورين ومديري التوظيف التقنيين.
- **التفاعل الصغير المبهج (Micro-interactions):** كل حركة تحوم (hover) أو ضغطة زر تكون معززة باستجابة حركية رشيقة تزيد من الإحساس بالحيوية والاستجابة.

## 2. Color Palette (Dark & Light Modes)

تم اختيار الألوان باستخدام قيم **HSL** لسهولة اشتقاق الشفافية والتناغم البصري.

```
┌─────────────────────────────────────────────────────────────────┐
│                           Color Tokens                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Dark Background: HSL(224, 40%, 7%)    [Deep Navy]              │
│  Accent Primary:  HSL(245, 80%, 60%)   [Tech Indigo]            │
│  Accent Secondary: HSL(195, 80%, 50%)  [Neon Cyan]              │
│  Semantic Success: HSL(142, 70%, 45%)  [Emerald Green]          │
│  Semantic Warning: HSL(38, 90%, 55%)   [Neon Amber]             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### Color Palette Details Table

| Token Name | Dark Mode Value | Light Mode Value | Purpose |
|------------|-----------------|------------------|---------|
| **Background-Primary** | `hsl(224, 40%, 7%)` | `hsl(0, 0%, 100%)` | Main layout background |
| **Background-Secondary**| `hsl(224, 40%, 12%)`| `hsl(220, 15%, 96%)`| Cards and modal backgrounds |
| **Accent-Primary** | `hsl(245, 80%, 60%)` | `hsl(245, 80%, 50%)` | Primary buttons, active states |
| **Accent-Secondary** | `hsl(195, 80%, 50%)` | `hsl(195, 80%, 40%)` | Links, tags, hover states |
| **Text-Primary** | `hsl(210, 20%, 98%)` | `hsl(224, 40%, 12%)` | Main body copy, titles |
| **Text-Secondary** | `hsl(215, 15%, 75%)` | `hsl(220, 10%, 45%)` | Captions, dates, meta info |
| **Border-Tech** | `hsla(215, 20%, 25%, 0.4)`| `hsla(220, 10%, 80%, 0.5)`| Glassmorphism card borders |

## 3. Typography Scales | الخطوط والطباعة

لضمان توافق مثالي للغات، نستخدم خطين مختلفين متناسقين بصرياً:

- **الإنجليزية (English):** خط `Inter` — خط تقني حاد يتميز بالتناسق التام في ارتفاع الأحرف.
- **العربية (Arabic):** خط `IBM Plex Sans Arabic` — خط تقني حديث ذو وضوح ممتاز بمرئيات الشاشة.

### Typography Scale (Fluid Typography):

| Level | Font Size (rem) | Line Height | Weight | Purpose |
|-------|-----------------|-------------|--------|---------|
| **Display H1** | `2.5rem - 3.75rem`| 1.1 | 700 (Bold) | Large landing hero statements |
| **Section H2** | `1.75rem - 2.25rem`| 1.2 | 600 (Semibold)| Module headings |
| **Card H3** | `1.25rem - 1.5rem`| 1.3 | 600 (Semibold)| Item titles |
| **Body LG** | `1.125rem` | 1.6 | 400 (Regular) | Introductory copy, first paragraphs |
| **Body MD** | `1.0rem` | 1.6 | 400 (Regular) | Primary text, article copy |
| **Caption** | `0.875rem` | 1.4 | 500 (Medium) | Timestamps, tags, UI badges |

## 4. Grid & Spacing System | نظام الفراغات والشبكة

نستخدم نظام فراغات معتمد على مضاعفات الرقم **4px (0.25rem)** لضمان محاذاة رياضية منضبطة لجميع الواجهات:

- **Grid Breakpoints:**
  - `Mobile` (default): 4 columns, `gap-4` (16px).
  - `Tablet` (>=768px): 8 columns, `gap-6` (24px).
  - `Desktop` (>=1200px): 12 columns, `gap-8` (32px), `max-w-7xl` (1280px max content width).
- **Spacing Tokens:**
  - `xs`: `0.25rem` (4px) -> Border padding, micro spacing.
  - `sm`: `0.5rem` (8px) -> Badge padding, text to image spacing.
  - `md`: `1.0rem` (16px) -> Card internal padding, standard margins.
  - `lg`: `1.5rem` (24px) -> Sections gaps, large paddings.
  - `xl`: `3.0rem` (48px) -> Hero section layout margins.

## 5. Standard UI Components Library | مكتبة المكونات القياسية

### 5.1 الأزرار (Buttons):
- **الزر الرئيسي (Primary):** خلفية بلون `Accent-Primary` مع انتقال لوني تدريجي (gradient) خفيف، يتحول لون الحدود لـ `Accent-Secondary` عند التحويم (hover).
- **الزر الثانوي (Secondary):** حدود بلون `Border-Tech` مع خلفية شفافة، تمتلئ بـ `Accent-Primary` بشكل متلاشٍ ورشيق عند التحويم.

### 5.2 صناديق المحتوى المتألقة (Glass Cards):
- صناديق بـ `backdrop-filter: blur(12px)` وخلفية ذات تعتيم `background: rgba(11, 15, 25, 0.7)` وحدود رقيقة جداً شبه شفافة `border: 1px solid rgba(255, 255, 255, 0.08)`. يمنح هذا المظهر تأثيراً مشابهاً للزجاج المفرغ المتألق على خلفية الموقع النجمية المعتمة.

### 5.3 صندوق المحادثة الذكي (RAG Chat UI):
- **فقاعات الرسائل (Message Bubbles):**
  - رسائل الزائر (User): تظهر بمحاذاة اليمين (في RTL) بخلفية `Accent-Primary` وتدرج مائل.
  - رسائل المساعد (AI): تظهر بمحاذاة اليسار (في RTL) بخلفية `Background-Secondary` مع أيقونة المساعد الفضية.
- **مؤشر الكتابة (Typing Indicator):** ثلاث نقاط تتأرجح بنعومة (pulsing animation) عند انتظار بث الكلمات.
