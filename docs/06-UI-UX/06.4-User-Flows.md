## 1. User Personas

يهدف تصميم رحلات المستخدمين إلى تلبية الاحتياجات الفريدة للجمهورين المستهدفين الأساسيين وفقاً لـ PRD §3:

1. **مدير التوظيف (Recruiter):** يبحث عن الأسماء اللامعة (Amazon/Grammarly) والتوثيق السريع السلس لإثبات الكفاءة (يملك وقت قراءة يقل عن 60 ثانية).
2. **المقيّم التقني (Technical Lead / Hiring Manager):** يبحث عن التفاصيل التقنية الدقيقة، جودة الكود، سجل القرارات والمقاييس البرمجية التي تثبت جدارة المرشح عملياً.

## 2. Recruiter Journey (Pedigree to Engineering Evidence)

توضح خريطة التدفق التالية رحلة مسؤول التوظيف من لحظة دخوله الموقع وحتى الوصول لوثيقة الخبرة وتأكيد الجدارة الفنية:

```mermaid
flowchart TD
    %% Styling definitions
    classDef page fill:#3b82f6,stroke:#1d4ed8,stroke-width:2px,color:#fff;
    classDef check fill:#eab308,stroke:#ca8a04,stroke-width:2px,color:#333;
    classDef action fill:#10b981,stroke:#047857,stroke-width:2px,color:#fff;

    Start([Recruiter lands on /en]) --> HeroText[1. View Hero Section<br/>See Amazon/Grammarly pedigree]:::page
    HeroText --> ClickResume[2. Click 'Interactive Resume']:::page
    
    ClickResume --> FilterSkills[3. Toggle Skill Filter<br/>Verify AI/LLM experience]:::page
    FilterSkills --> CheckConfidentiality{Wants detailed case study?}:::check
    
    CheckConfidentiality -- Yes --> ClickExp[4. Navigate to /experience/amazon]:::page
    CheckConfidentiality -- No --> DownloadPDF[5. Click 'Download PDF Resume']:::action
    
    ClickExp --> ViewCaseStudy[6. Read NDA-safe case study<br/>Confirm seniority & impact]:::page
    ViewCaseStudy --> ClickContact[7. Navigate to /contact<br/>Send interview invitation]:::action
    DownloadPDF --> ClickContact
```

## 3. Technical Interviewer Journey (Assistant Evaluation)

يريد المقيّم التقني التحقق من أن مساعد الـ RAG الذكي ليس مجرد واجهة بسيطة بل تم هندسته وقياس أدائه بصرامة:

```mermaid
flowchart TD
    %% Styling definitions
    classDef page fill:#3b82f6,stroke:#1d4ed8,stroke-width:2px,color:#fff;
    classDef check fill:#eab308,stroke:#ca8a04,stroke-width:2px,color:#333;
    classDef action fill:#10b981,stroke:#047857,stroke-width:2px,color:#fff;

    Start([Interviewer lands on /]) --> OpenChat[1. Open AI Assistant Widget]:::page
    OpenChat --> MixedQuery[2. Type mixed EN/AR technical query]:::page
    
    MixedQuery --> ReceiveSSE[3. Observe smooth streaming SSE response<br/>Check Arabic grammar quality]:::page
    ReceiveSSE --> GoToProjects[4. Click link in chat to /projects/rag-assistant]:::page
    
    GoToProjects --> ReadEvidence[5. Read 'Engineering Evidence'<br/>Inspect chunking & indexing design]:::page
    ReadEvidence --> ClickEvalPanel[6. Click 'LLM Observability Panel' widget]:::page
    
    ClickEvalPanel --> InspectMetrics[7. Inspect live token costs, latencies,<br/>and golden-set pass rates]:::page
    InspectMetrics --> ClickContact[8. Trigger contact form for technical screening]:::action
```

## 4. Administrator Journey (Observability & Ingestion)

يوضح مسار الإدارة للمسؤول لإجراء مهام الصيانة اليومية ومراجعة الجودة:

```mermaid
sequenceDiagram
    autonumber
    actor Admin as Whitelisted Administrator
    participant UI as Admin Dashboard
    participant API as Next.js BFF API
    participant FastAPI as FastAPI Backend
    participant DB as PostgreSQL

    Admin->>UI: Go to /admin (Google OAuth Authenticated)
    UI->>API: GET /api/admin/metrics
    API->>FastAPI: Forward request with Bearer JWT
    FastAPI->>DB: Query aggregated latency & cost trends
    DB-->>UI: Render analytical charts (Recharts)
    
    Admin->>UI: Click "Trigger Evaluation Run"
    UI->>API: POST /api/v1/eval (Trigger batch run)
    API->>FastAPI: Launch background async evaluation job
    FastAPI-->>UI: Return 202 Accepted (Processing)
    
    Note over Admin, UI: Later...
    Admin->>UI: View Chat logs list
    UI->>DB: Query last 20 queries & evaluation pass results
    DB-->>UI: Render logs grid highlighting failed evaluations (passed = false)
```
