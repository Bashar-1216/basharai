## 1. Sitemap & Route Architecture

نظام المسارات المتبع يعتمد بالكامل على بادئة اللغة الديناميكية لدعم ثنائية اللغة:

```
 /{locale}/
    ├── (Home)                        ← Landing Page
    ├── about                         ← Resume / Timeline / Skills
    ├── resume                        ← Interactive CV + PDF
    ├── experience                    ← Professional Case Studies (Amazon/Grammarly)
    ├── projects                      ← Engineering Showcase
    │     └── [slug]                  ← Deep Technical Evidence (RAG/Eval details)
    ├── blog                          ← Tech Articles
    │     └── [slug]                  ← Article Reader
    └── contact                       ← Hire / Contact Forms
 /admin                               ← Secured login redirection (Google/GitHub)
    ├── dashboard                     ← Observability Analytics UI
    └── logs                          ← Chat Logs auditor
```

## 2. Public Pages Inventory | جرد الصفحات العامة

توضح القائمة التالية تفاصيل كافة الصفحات المتاحة لعامة الزوار والشركات:

### 2.1 الصفحة الرئيسية (Landing Page - `/`):
- **الغرض:** تقديم بيان تحديد الهوية الحاد (Positioning Statement) للمرشح وإبهار الزائر بالمظهر الرقمي المتقدم من أول 3 ثوانٍ.
- **العناصر البصرية الرئيسية:**
  - قسم العنوان الرئيسي (Hero Section) مع بيان الكفاءة المزدوج (Amazon + Grammarly).
  - نافذة المساعد الذكي المدمجة (AI Chat Widget) في الزاوية لحث الزائر على التفاعل الفوري.
  - روابط سريعة لدراسات الحالة المميزة (Projects showcase).

### 2.2 صفحة السيرة الذاتية التفاعلية (Resume - `/resume`):
- **الغرض:** عرض التايم لاين الوظيفي بشكل تفاعلي يسمح لمدير التوظيف بتصفية المهارات وتصفح الإنجازات مع زر لتحميل ملف PDF المهيأ للطباعة باللغتين.
- **العناصر البصرية الرئيسية:**
  - جدول مهارات تفاعلي (Interactive skill filter).
  - زر تحميل PDF واضح وثنائي الترويسة.

### 2.3 صفحة خبرات العمل (Experience - `/experience`):
- **الغرض:** استضافة دراسات الحالة المهنية الخاصة بـ Amazon و Grammarly بشكل مؤمن ومتوافق مع اتفاقيات السرية (NDA-safe).
- **العناصر البصرية الرئيسية:**
  - ترويسة توضح نطاق السرية بوضوح (Confidentiality warning badge).
  - هيكل قراءة مريح يعتمد على سرد المشاكل والأثر الفعلي بلغة عامة ومحترفة.

### 2.4 صفحة المشاريع التقنية التفصيلية (Projects - `/projects/[slug]`):
- **الغرض:** تقديم **الأدلة الهندسية (Engineering Evidence)** الكاملة بدون قيود NDA.
- **العناصر البصرية الرئيسية:**
  - رسم توضيحي للمشروع (Architecture layout).
  - سجل القرارات التقنية (Trade-offs log).
  - جزء مخصص لعرض مقاييس دقة النموذج المسترجعة من حلقة التقييم.

## 3. Admin Panel Screens Inventory | جرد لوحة التحكم للمسؤول

تتطلب هذه الصفحات التحقق من الهوية وصلاحيات `ADMIN`:

### 3.1 لوحة مراقبة الأداء والتحليلات (Dashboard - `/admin`):
- **الغرض:** عرض تحليلات استهلاك الذكاء الاصطناعي وجودة إجابات RAG لدعم العرض التقديمي للمرشح.
- **العناصر التفاعلية:**
  - رسوم بيانية (Cost trends over time, Latency distribution charts).
  - لوحة التحكم لإطلاق اختبارات التقييم اليدوية (Trigger manual evaluations).

### 3.2 مراقب المحادثات (Logs Auditor - `/admin/logs`):
- **الغرض:** تفتيش ومراجعة سجلات المحادثات وتعديل فلتر البيانات لرصد تراجع الأداء أو محاولات الاختراق.
- **العناصر التفاعلية:**
  - جدول تصفية يبحث بالكلمات المفتاحية واللغة والنجاح التقييمي.
  - نافذة عرض محتوى المحادثة الكامل وتفاصيل الـ retrieved chunks لكل طلب.

## 4. Navigation & Layout Structure

- **رأس الصفحة (Navbar Header):**
  - يحتوي على قائمة روابط المسارات العامة، زر التبديل بين اللغتين (AR/EN Locale Toggle) وزر تبديل المظهر (Dark/Light Mode).
  - في صفحات RTL (العربية)، يعاد توزيع العناصر تلقائياً لتكون الشعار في اليمين والروابط والتبديل في اليسار.
- **تذييل الصفحة (Footer):**
  - يحتوي على حقوق الملكية الفكرية، روابط شبكات التواصل الاجتماعي (LinkedIn, GitHub)، ورسالة فنية طريفة توضح أن الموقع مدعوم بنظام RAG ذاتي المراقبة بالكامل.
