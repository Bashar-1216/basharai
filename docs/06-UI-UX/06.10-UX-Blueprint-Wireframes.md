## 1. Homepage Layout & Hierarchy | هيكلية الصفحة الرئيسية

تتبع الصفحة الرئيسية تسلسلاً منطقياً هادئاً، مقسماً بألواح الورق الرقمي (Paper Panels) والخطوط الرفيعة:

### 1.1 Wireframe Layout:
```
+-------------------------------------------------------------------------+
| [bashar.ai]               Experience   Projects   AI Assistant  [EN/AR] |
| ======================================================================= |
|                                                                         |
|  LLM Application Engineer                                               |
|  Production AI systems at Amazon & Grammarly.                           |
|  Building bilingual LLM platforms for GCC and global teams.            |
|                                                                         |
|  [ Explore Experience ]                          [Latest Eval: 97.8% 🟢] |
|                                                                         |
| ----------------------------------------------------------------------- |
|  [Summary metrics] Latency: 480ms | Cost: $0.004/req                    |
+-------------------------------------------------------------------------+
```

### 1.2 UX Analysis:
- **الغرض:** تقديم المرشح وتأكيد تخصصه وجودة النظام فوراً.
- **ماذا يرى أولاً؟** المسمى الوظيفي الصريح وتجربته في أمازون وجرامرلي (Emotion).
- **ماذا يضغط؟** زر `[ Explore Experience ]` للتمرير التلقائي السلس لقسم السيرة الذاتية أو زر تبديل اللغة.

## 4. AI Chat Interface: Simple vs. Developer Console

نطبق واجهة المحادثة ثنائية الأبعاد (Dual-Mode Interface) لتخدم الزائر العادي والتقني معاً:

### 4.1 Wireframe Layout:
```
+------------------------------------------+------------------------------+
| 🤖 SYSTEM CONSOLE: RAG ASSISTANT         | ⚙️ SYSTEM METRICS [x] Close  |
| ---------------------------------------- | ---------------------------- |
| [Visitor]: Tell me about NLP work.       | Model: gpt-4o-mini           |
| [Assistant]: Bashar built transformer    | Latency: 420ms               |
| pipelines at Grammarly...                | Cost: $0.003                 |
|                                          | Tokens: 480 In / 120 Out     |
| ---------------------------------------- | Confidence: 94.2%            |
| > Ask a question...                  [>] | Source: experience/nlp.md    |
+------------------------------------------+------------------------------+
```

### 4.2 UX Analysis:
- **التفاعل:** يدخل المستخدم في محادثة بسيطة. عند رغبته في التدقيق، يضغط على `[ Developer View ]` لتظهر اللوحة الجانبية اليمنى فوراً بشكل منزلق ناعم.
