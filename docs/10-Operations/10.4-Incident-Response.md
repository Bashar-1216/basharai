## 1. Incident Severity Classification

نصنف المشاكل الفنية الطارئة إلى ثلاثة مستويات لتحديد نطاق وسرعة التدخل والتعافي:

- **Severity 1 (الحرج الأقصى):** الموقع بالكامل متوقف عن العمل ولا يستجيب (خادم Next.js معطل أو قاعدة البيانات الرئيسية تالفة بالكامل).
- **Severity 2 (الخلل الجزئي للذكاء الاصطناعي):** الموقع والصفحات والسيرة الذاتية يعملون بشكل ممتاز، ولكن مساعد الـ RAG لا يستجيب للأسئلة أو يرجع أخطاء 500 مستمرة.
- **Severity 3 (المشاكل البسيطة):** أخطاء إملائية في الترجمات، أو عدم محاذاة خفيفة لبعض كروت المشاريع في شاشات معينة دون تعطيل التصفح.

## 2. Incident Response Procedures (4-Step Flow)

عند رصد عطل فني أو استقبال إشعار حرج، نتبع المسار المعياري التالي للحل والتعافي:

```
 ┌──────────────┐      ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
 │  1. Detect   │ ──►  │  2. Triage   │ ──►  │ 3. Mitigate  │ ──►  │  4. Resolve  │
 └──────────────┘      └──────────────┘      └──────────────┘      └──────────────┘
  Auto Alerts /         Isolate issue;        Apply Rollback        Fix root cause;
  Interviewer           Check logs &          or Toggle flag        Write permanent
  feedback              Health check          Kill Switch           Post-Mortem
```

1. **الاستكشاف (Detect):** استقبال تنبيه Uptime Robot أو Discord.
2. **التصنيف والتفتيش (Triage):** التحقق من الـ Logs محلياً أو عبر Railway Console لرصد مسبب الخطأ البرمجي وسحب الـ Correlation ID المتأثر.
3. **التخفيف الفوري (Mitigate):** 
   - إذا كان الخلل في ميزات الـ AI المحدثة، نقوم فوراً بتفعيل **مفتاح الإطفاء (Kill Switch)** لـ `FLAG_CHAT_ENABLED = false` ليعود الموقع للعمل الثابت وتتوقف تكاليف OpenAI فوراً.
   - إذا كان الخلل معطلاً لكامل النظام، نقوم بعمل **تراجع فوري (Rollback)** للنسخة السابقة المستقرة.
4. **الحل والتحليل (Resolve & Post-Mortem):** إصلاح الكود وإجراء الاختبارات اللازمة وإعادة النشر بأمان، ثم كتابة تحليل الحادث لمنع التكرار.

### 3.1 رسالة صيانة المساعد الذكي (Severity 2 UI fallback message):
- **EN:** *"The AI Assistant is currently undergoing scheduled optimization to improve retrieval accuracy. Feel free to browse the resume and projects below, or contact me directly."*
- **AR:** *"يمر مساعد الذكاء الاصطناعي حالياً بعملية تحسين وجدولة لرفع دقة استرجاع البيانات. نسعد بتصفحك للسيرة الذاتية والمشاريع بالأسفل، أو يمكنك التواصل معي مباشرة."*
