## 1. Cost Architecture Overview

بما أن منصة bashar.ai هي مشروع هندسي شخصي، فإن **إدارة التكاليف السحابية (Cost Management)** وضبط الحدود المالية هي مسألة بالغة الأهمية لتفادي صدمات الفواتير المرتفعة، مع الحفاظ على أداء متميز ومطابق للإنتاج.

### خريطة تكاليف الاستضافة المتوقعة (Hobby Tier Hosting):

- **Next.js Frontend (Vercel):** مجانية بالكامل (`$0/month`).
- **CDN, DNS, SSL (Cloudflare):** مجانية بالكامل (`$0/month`).
- **Postgres, Redis, FastAPI (Railway):** تكلفة استهلاك مرنة تبدأ من **$5** وتصل بحد أقصى لـ **$10 شهرياً**.
- **إجمالي التكلفة الثابتة:** أقل من **$10 شهرياً**.

## 2. OpenAI API Cost Management (GPT-4o-mini)

يمثل استدعاء النماذج اللغوية OpenAI API التكلفة المتغيرة الأكبر للمشروع. قمنا باختيار النموذج ذو الكفاءة العالية والتكلفة المنخفضة جداً **`gpt-4o-mini`**:

- **أسعار النموذج (Pricing Matrix):**
  - توكنز المدخلات (Input Tokens): **$0.15 لكل مليون توكن**.
  - توكنز المخرجات (Output Tokens): **$0.60 لكل مليون توكن**.
- **الحدود المالية الصارمة (Hard & Soft Limits):**
  - يتم تهيئة الحساب في لوحة تحكم OpenAI لوضع **حد أقصى صارم (Hard Limit) بقيمة $10.00 شهرياً**، حيث يرفض الحساب أي طلب إضافي بعد تجاوزه لحماية الميزانية بالكامل.
  - وضع **حد إشعار مرن (Soft Limit) بقيمة $5.00 شهرياً** لإرسال بريد إلكتروني تحذيري للمسؤول للمراجعة والتدقيق.

## 3. Token Conservation Strategies (Redis Caching) | حماية التوكنز

لمنع استهلاك التوكنز في طلبات متكررة أو عبثية:

1. **ذاكرة استعلام الزوار (Redis Response Caching):**
   - عند استقبال سؤال RAG، نقوم بفحص محتواه في Redis.
   - إذا تم البحث عن نفس السؤال بدقة خلال آخر 24 ساعة (مثال: "ما هي مهاراتك؟")، نقوم بإرجاع الإجابة المخزنة مباشرة من Redis دون استدعاء OpenAI، مما يوفر تكلفة الـ API بنسبة **100%** وزمن الاستجابة للزائر.
2. **ضغط موجه النظام (System Prompt Compression):**
   - صياغة موجهات RAG ووثائق السيرة الذاتية بلغة مكثفة ومباشرة دون حشو لتوفير حجم المدخلات في كل طلب.

## 4. Cost-per-Visitor (CPV) Metrics Calculation

نحسب التكلفة المتوسطة لكل زائر (CPV) داخل خادم FastAPI ونعرضها في لوحة تحكم المسؤول `/admin` لرصد جودة التوليف:

$$\text{CPV} = \frac{\text{Total OpenAI API Cost (USD)}}{\text{Total Unique Session Count}}$$

- **الحد المستهدف (Target CPV):** أقل من **$0.02** لكل زائر فرعي (بما يعادل قرابة 2 سنت فقط لكل حوار RAG متكامل)، وهو ما يضمن استمرارية المحفظة وجاذبيتها التشغيلية دون أعباء مالية تذكر.
