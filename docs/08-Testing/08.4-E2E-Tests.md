## 1. E2E Testing Overview (Playwright)

تستهدف اختبارات النهاية للنهاية (E2E) محاكاة رحلات المستخدمين الحقيقية وتصرفات المتصفح بصرياً وحركياً، مع التركيز على **التحقق من صحة اتجاه الصفحة (RTL Layout)** وعرض النصوص ثنائية اللغة وتدفق البث في الوقت الحقيقي.

نستخدم **Playwright** لدعمه المدمج للغات المتعددة، والتقاط الصور التلقائي، والسرعة الفائقة في تشغيل السيناريوهات خلف الكواليس (Headless Mode) في CI pipelines.

## 2. Recruiter Journey Scenario (Bilingual & Layout Verifications)

- **الهدف:** التأكد من إمكانية وصول مسؤولي التوظيف للسيرة الذاتية وقراءة البيانات بالعربية والإنجليزية بسلاسة.
- **خطوات الفحص الأوتوماتيكية (Playwright Script Flow):**
  1. يفتح المتصفح الصفحة الرئيسية `http://localhost:3000/en`.
  2. يضغط على زر تبديل اللغة (Language switcher).
  3. **التحقق (Assertion):** التأكد من أن الرابط أصبح `http://localhost:3000/ar` ووسم الـ HTML يحمل الاتجاه `dir="rtl"`.
  4. يتنقل إلى صفحة السيرة الذاتية `/resume` ويتحقق من ظهور عناصر التايم لاين.
  5. يتحقق من وجود زر تحميل ملف السيرة الذاتية PDF وقابليته للضغط.

```typescript
// Sample E2E test verification snippet
import { test, expect } from "@playwright/test";

test("recruiter can switch language and see RTL layout", async ({ page }) => {
  await page.goto("/en");
  await page.click('[aria-label="Switch language to Arabic"]');
  await expect(page).toHaveURL(/\/ar/);
  
  const htmlDir = await page.getAttribute("html", "dir");
  expect(htmlDir).toBe("rtl");
  
  await page.goto("/ar/resume");
  await expect(page.locator("text=السيرة الذاتية")).toBeVisible();
});
```

## 3. AI Chat Interaction Scenario (SSE Streaming Validation)

- **الهدف:** التحقق من فتح نافذة المساعد وبث الإجابات تدريجياً في واجهة المستخدم.
- **خطوات الفحص الأوتوماتيكية:**
  1. يفتح المتصفح الصفحة الرئيسية ويفحص وجود نافذة المساعد (Chat widget).
  2. يضغط على زر فتح الشات لتظهر واجهة المحادثة.
  3. يكتب سؤالاً تجريبياً (مثال: "ما هي خبرتك؟") ويضغط على إرسال.
  4. **التحقق (Assertion):** مراقبة DOM والتحقق من ظهور مؤشر الكتابة (Typing Indicator).
  5. **التحقق 2:** انتظار بث الكلمات والتأكد من ظهور فقاعة المساعد تحتوي على ردود متدرجة من خادم FastAPI المكتمل.

## 4. Admin Console Journey Scenario (Mock Session & Charts)

- **الهدف:** فحص لوحة الإدارة ومراقبة التحليلات وتفاعل المسؤول دون المساس ببيانات الإنتاج.
- **خطوات الفحص الأوتوماتيكية:**
  1. إعداد كوكي مصادقة وهمية (Mocked session cookie) مسبقة الصلاحية لتخطي صفحة OAuth.
  2. يفتح المتصفح لوحة التحكم `/admin`.
  3. **التحقق (Assertion):** التأكد من ظهور عناصر الرسوم البيانية (Recharts SVGs) بنجاح وعرض متوسط سرعات الاستجابة.
  4. يضغط على زر "Trigger Evaluation Run" للتحقق من إطلاق المهمة وعرض شريط المعالجة بنجاح.
