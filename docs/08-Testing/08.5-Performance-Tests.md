## 1. Performance Budgets & SLA Targets

نضع قيوداً صارمة على **أزمنة الاستجابة (Latency Constraints)** لضمان تقديم منصة سريعة وخفيفة لمديري التوظيف واللجان الفنية:

- **واجهة العرض الثابتة (BFF Pages):** زمن الاستجابة للمتصفح أقل من **100ms** (بالاعتماد على التخزين المؤقت وحوسبة الحافة Vercel Edge).
- **الاستعلامات لقاعدة البيانات (DB Lookup):** عمليات البحث المتجهي في pgvector أقل من **50ms** (باستخدام فهارس HNSW المجهزة).
- **زمن بث الكلمة الأولى للـ RAG (First-Token Latency):** أقل من **350ms** عند بدء استدعاء معالج OpenAI.
- **زمن الاستجابة الكامل للـ RAG (Complete Answer Build):** أقل من **2.5 ثانية** للردود متوسطة الطول.

## 2. Load Testing Configurations (k6 by Grafana)

نستخدم أداة **k6** لمحاكاة زيارات جماعية متزامنة والتأكد من عدم تعطل الخدمات تحت الضغط.

### 2.1 اختبار فحص الحجم المتزامن (Concurrent Chat Load Test):
- **السيناريو:** تشغيل 50 زائرًا افتراضيًا متزامنًا (50 Virtual Users) يقومون بإرسال أسئلة RAG بشكل دوري وخوض حوارات متوازية مع المساعد الذكي.
- **كود الفحص (k6 JS script):**
```javascript
import http from 'k6/http';
import { sleep, check } from 'k6';

export const options = {
  stages: [
    { duration: '30s', target: 50 },  // Ramp up to 50 users
    { duration: '1m', target: 50 },   // Stay at 50 users
    { duration: '30s', target: 0 },   // Ramp down to 0
  ],
  thresholds: {
    http_req_duration: ['p(95)<3000'], // 95% of requests must complete under 3.0s
    http_req_failed: ['rate<0.01'],    // Error rate must be under 1%
  },
};

export default function () {
  const url = 'http://localhost:8000/api/v1/chat';
  const payload = JSON.stringify({
    message: 'ما هي مهاراتك الهندسية؟',
    sessionId: 'test_k6_fp',
  });
  
  const params = {
    headers: { 'Content-Type': 'application/json' },
  };
  
  const res = http.post(url, payload, params);
  check(res, {
    'status is 200': (r) => r.status === 200,
  });
  sleep(1);
}
```

## 3. Core Web Vitals Thresholds | مقاييس الويب الحيوية

نلتزم بتحقيق تصنيفات متميزة في اختبارات Lighthouse للأداء وتفاعل المتصفح (مقياس الأخضر الدائم):

* **LCP (Largest Contentful Paint):** أقل من **1.2 ثانية** (زمن رسم أكبر عنصر بصري بالصفحة).
* **FID (First Input Delay):** أقل من **100ms** (سرعة استجابة الموقع لأول ضغطة زر أو تفاعل).
* **CLS (Cumulative Layout Shift):** أقل من **0.05** (منع أي اهتزاز أو إزاحة مفاجئة للعناصر أثناء التحميل).

## 4. Stress Testing & Network Throttling Simulation

نقوم بمحاكاة ظروف الشبكات الضعيفة لضمان ثبات التصفح في دول الخليج والعالم:
- **تحجيم الشبكة (Network Throttling):** تشغيل اختبارات المتصفح Playwright تحت إعدادات محاكاة شبكات الجوال الضعيفة (Fast 3G / Slow 4G).
- **التأكد من خلو واجهة المحادثة من الكسر البصري:** التأكد من إظهار مؤشرات تحميل واضحة وصغيرة (Loading spinner/skeleton) للمستخدم ليعرف أن العملية تحت المعالجة ولا يظن أن الموقع قد تعطل.
