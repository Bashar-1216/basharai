## 1. Accessibility Validation Strategy

لضمان سهولة تصفح الموقع بالكامل لمديري التوظيف واللجان الفنية من ذوي الاحتياجات الحركية والبصرية، نضع مساراً صارماً لاختبارات الوصولية يدمج الفحص الآلي المستمر (Automated Audit) مع التدقيق اليدوي لسيناريوهات استخدام لوحة المفاتيح وقارئات الشاشة.

---

## 2. Automated Accessibility Auditing (Axe-Core)

نستخدم مكتبة **`@axe-core/playwright`** لدمج الفحص الآلي المستمر للوصولية ضمن خط أنابيب اختبارات الـ E2E.

- **آلية العمل:**
  - مع كل اختبار صفحة E2E، يقوم Playwright بحقن محرك Axe-Core وتحليل شجرة عناصر الصفحة (DOM) بالكامل.
  - يفحص المحرك: نسب التباين اللوني، وجود نصوص بديلة للصور (`alt` tags)، وربط حقول الإدخال بعناوينها (`label` matches).
- **كود الفحص الافتراضي (Axe integration in Playwright):**
```typescript
import { test, expect } from "@playwright/test";
import injectAxe, { checkA11y } from "@axe-core/playwright";

test("home page has no accessibility violations", async ({ page }) => {
  await page.goto("/en");
  await injectAxe(page);
  
  // Scans the entire page and asserts zero critical WCAG AA violations
  await checkA11y(page, null, {
    axeOptions: {
      runOnly: {
        type: "tag",
        values: ["wcag2a", "wcag21aa"],
      },
    },
  });
});
```

## 3. Manual Keyboard Navigation Checklist | فحص لوحة المفاتيح يدوياً

نظراً لأن الفحص التلقائي يرصد العيوب التركيبية فقط، فإننا نلتزم بتشغيل قائمة التحقق اليدوية التالية دورياً:

- [ ] **Skip Link Validation:** التأكد من ظهور رابط "التخطي للمحتوى" عند ضغط زر `Tab` لأول مرة عند فتح الصفحة وتحويل المؤشر مباشرة لـ `<main>`.
- [ ] **Visual Focus Indicator:** وضوح حدود التركيز البصرية (Focus Ring) على كافة الأزرار والروابط دون اختفاء.
- [ ] **Modal Focus Trap:** حصر مؤشر التركيز داخل صندوق المحادثة المفتوح (Chat drawer) أو القائمة المنزلقة ومنع تسربه للخلفية.
- [ ] **Escape Key Action:** إغلاق المحادثة أو القوائم المنزلقة فوراً بالضغط على زر `Esc` وإرجاع التركيز للزر المسبب للفتح.

## 4. Bilingual Screen Reader Testing (NVDA / VoiceOver)

نختبر جودة وتدفق القراءة الصوتية باللغتين العربية والإنجليزية للتأكد من المواءمة الصوتية للزوار:

- **اختبار لغة الترميز (HTML Lang Check):**
  - التأكد من تغيير قيمة الوسم `lang="ar"` في الصفحة العربية و `lang="en"` في الإنجليزية ليقوم قارئ الشاشة بتبديل نبرة النطق والصوت آلياً دون تشوه صوتي.
- **فحص بث محادثة الـ RAG الذكي:**
  - التحقق من تفعيل `aria-live="polite"` على حاوية البث الصادر لضمان قراءة الكلمات المستجدة بوضوح للمستخدم دون مقاطعة حركته.
