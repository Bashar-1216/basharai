## 2. Sprint 0 — Environment Setup & Baseline (Week 1)

- **هدف السبرنت:** تهيئة مستودع الأكواد الموحد (Monorepo) وضبط الحاويات المحلية ومتغيرات البيئة للبدء فوراً دون تعقيدات.
- **المهام الرئيسية:**
  - كتابة ملفات Docker Compose لتشغيل PostgreSQL (مع pgvector) و Redis محلياً.
  - إعداد بيئة TypeScript (Next.js) و Python (FastAPI).
  - كتابة وتفعيل أدوات الفحص والتنسيق الآلي (Ruff & Biome) مع خطافات Git (Husky pre-commit).
- **معيار الخروج (Exit Criteria):**
  - تشغيل الأمر `docker compose up -d` بنجاح محلياً وتوفر قاعدة بيانات و خادم FastAPI خامل جاهزين للاستجابة.

---

## 3. Sprint 1 — Core Portfolio MVP (Weeks 2-3)

- **هدف السبرنت:** بناء الواجهة البصرية للموقع، ترجمات واجهة المستخدم، وتأكيد الهوية المهنية للمرشح (pedigree).
- **المهام الرئيسية:**
  - بناء صفحات الهيكل (Landing, About, Resume, Experience) بالاعتماد على Next.js Server Components.
  - دمج مكتبة `next-intl` وضبط توجيه الروابط ثنائية اللغة RTL/LTR.
  - صياغة محتوى السيرة الذاتية التفاعلية وخبرات أمازون وجرامرلي (NDA-safe).
  - ربط وتفعيل Prisma ORM وزرع البيانات الأولية (Experiences seed).
- **معيار الخروج (Exit Criteria):**
  - الموقع يعمل محلياً بالكامل باللغتين مع إمكانية التنقل وتحميل ملف PDF والتوافقية التامة للجوال.

---

## 4. Sprint 2 — RAG Engine & Streaming Chat (Weeks 4-5)

- **هدف السبرنت:** شحن مساعد الذكاء الاصطناعي RAG وتأمين حدوده المالية والبرمجية.
- **المهام الرئيسية:**
  - إعداد كود معالجة وتجزئة مستندات الـ MDX المتواجدة في Git محلياً وتوليد الـ embeddings وحفظها في pgvector.
  - كتابة موجهات RAG (System prompt) الصارمة ثنائية اللغة لمنع الهلوسة في FastAPI.
  - تفعيل بث الإجابات (SSE streaming) وربطه بمكون واجهة مستخدم الـ Chat Widget (Client component).
  - إعداد Rate Limiting (Redis-based token bucket) وهويات البصمات غير المسجلة.
- **معيار الخروج (Exit Criteria):**
  - مساعد الموقع الذكي يستجيب ويبث الكلمات في زمن استجابة مدرك يقل عن 300ms ويرفض الطلبات بعد تجاوز الـ Limit المتاح.

---

## 5. Sprint 3 — Observability & Eval Dashboard (Weeks 6-7)

- **هدف السبرنت:** بناء محرك المراقبة والتحقق التلقائي وشاشة عرض الإحصائيات للمسؤول والزوار.
- **المهام الرئيسية:**
  - إعداد المكونات البرمجية الوسيطة (Middlewares) لتسجيل تفاصيل استدعاء RAG (التكلفة، زمن الاستجابة، الرموز) غير المتزامنة في قاعدة البيانات.
  - تطوير كود الفحص التلقائي لمقاييس RAG Triad ضد الأسئلة الذهبية (Golden set).
  - بناء لوحة التحكم ومراقبة الأداء `/admin` وربطها برسم بياني تفاعلي (Recharts) وتفاصيل السجل البرمجي.
- **معيار الخروج (Exit Criteria):**
  - توفر لوحة إحصائيات عامة تفاعلية تعرض تكاليف حقيقية للاستخدام ومتوسط أوقات الاستجابة للذكاء الاصطناعي مع توثيق آخر تقييم للجودة.

---

## 6. Sprint 4 — Hardening, SEO & Live Launch (Week 8)

- **هدف السبرنت:** تدقيق الأمان والوصولية والسرعة وإطلاق النسخة الحية على شبكة الإنترنت.
- **المهام الرئيسية:**
  - فحص ومطابقة الموقع لمعايير الوصولية WCAG 2.1 AA (Aria tags, Keyboard nav, screen reader check).
  - فحص سرعة الموقع وإلغاء فوارق المحاذاة (Lighthouse audit 95+).
  - تهيئة النطاق bashar.ai وتوجيه السجلات وتأمين HTTPS.
  - تفعيل خط أنابيب النشر النهائي CI/CD Preview PRs والإنتاج.
- **معيار الخروج (Exit Criteria):**
  - الموقع حي ومتاح على الإنترنت بنسبة 100% ويقدم الأدلة الهندسية بوضوح تام لجميع الزوار.
