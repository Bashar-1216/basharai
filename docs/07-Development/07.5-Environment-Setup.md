## 1. Required Local Tools

لتشغيل كامل مكونات المنصة محلياً، يجب توفر وتثبيت الأدوات البرمجية التالية على جهاز المطور:

- **Git:** لإدارة النسخ وتتبع الفروع.
- **Node.js (v20 أو v22 LTS):** خادم تشغيل Next.js.
- **pnpm (Package Manager):** بديل سريع وموفر للمساحة لـ npm.
- **Python (v3.12):** بيئة تشغيل FastAPI.
- **uv (Python Package Manager):** بديل فائق السرعة لـ pip لإدارة الحزم الافتراضية.
- **Docker & Docker Compose:** لتشغيل قواعد بيانات PostgreSQL و Redis بنسخ مطابقة للإنتاج دون تثبيتها يدوياً في النظام.

## 2. Step-by-Step Setup Guide | خطوات التهيّئة

نتبع الخطوات المتسلسلة التالية لبدء العمل من الصفر:

### الخطوة 1: استنساخ المستودع وتهيئة المتغيرات البيئية
```bash
# Clone the repository
git clone https://github.com/yourusername/basharai.git
cd basharai

# Create local env files from templates
cp src/frontend/.env.template src/frontend/.env.local
cp src/backend/.env.template src/backend/.env
```

### الخطوة 2: تشغيل قواعد البيانات والذاكرة المؤقتة (Docker)
تأكد من تشغيل Docker Desktop محلياً، ثم نفّذ الأمر التالي من جذر المشروع:
```bash
docker compose up -d
```
*سيقوم Docker بتحميل وتشغيل PostgreSQL (المجهزة بـ pgvector) و Redis في الخلفية.*

## 3. Local Services Configuration (Docker Compose)

نستخدم الإعدادات التالية لتشغيل الخدمات المحلية وضمان مطابقة بيئة الإنتاج:

```yaml
# docker-compose.yml
version: '3.8'
services:
  database:
    image: ankane/pgvector:v0.5.1 # PostgreSQL loaded with pgvector
    ports:
      - "5432:5432"
    environment:
      POSTGRES_USER: local_developer
      POSTGRES_PASSWORD: local_secure_password
      POSTGRES_DB: bashar_db
    volumes:
      - pgdata:/var/lib/postgresql/data

  redis:
    image: redis:7.2-alpine
    ports:
      - "6379:6379"
    volumes:
      - redisdata:/data

volumes:
  pgdata:
  redisdata:
```

## 4. BFF & Next.js Local Launch

تنزيل التبعيات وتشغيل خادم Next.js:

```bash
cd src/frontend

# Install dependencies using pnpm
pnpm install

# Run Prisma schema generation and push migrations to local DB
pnpm prisma db push

# Seed the database with base experience data (Amazon/Grammarly)
pnpm prisma db seed

# Start local Next.js development server
pnpm dev
```
*الواجهة الأمامية متاحة الآن على الرابط: `http://localhost:3000`.*

## 5. FastAPI Backend Local Launch

تجهيز وتشغيل خادم تطبيقات FastAPI للذكاء الاصطناعي:

```bash
cd src/backend

# Create virtual environment and install dependencies using uv
uv venv
uv pip install -r pyproject.toml

# Activate virtual environment
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate

# Run FastAPI server with hot-reload enabled
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
*خادم FastAPI متاح الآن على الرابط: `http://localhost:8000`. ويمكن تصفح توثيق OpenAPI التفاعلي (Swagger UI) على الرابط: `http://localhost:8000/docs`.*

## 6. Troubleshooting & Ports Reference

### 6.1 مرجع المنافذ المحلية (Local Ports):
- `3000`: Next.js Client & BFF
- `8000`: FastAPI Backend
- `5432`: PostgreSQL (Neon/Supabase replacement)
- `6379`: Redis (Upstash replacement)

### 6.2 أخطاء شائعة والتعافي منها:
- **Port Conflict (5432 already in use):**
  - **السبب:** وجود نسخة PostgreSQL محلية مثبتة تعمل في خلفية النظام.
  - **الحل:** قم بإيقاف خادم PostgreSQL المحلي من نظام الخدمات، أو قم بتغيير منفذ الخروج في ملف `docker-compose.yml` إلى `5433:5432` وتحديث الـ `DATABASE_URL` تبعا لذلك.
- **Docker daemon is not running:**
  - **الحل:** افتح برنامج Docker Desktop وانتظر حتى يتحول مؤشر الحالة للون الأخضر، ثم أعد محاولة تشغيل الأمر.
