## 1. Seed Data Strategy

تضمن البيانات الأولية (Seed Data) تشغيل المنصة فورياً بعد عملية النشر الأولى بمحتوى غني وحقيقي دون شاشات فارغة أو نصوص تجريبية (Lorem Ipsum).

نصنف البيانات الأولية إلى ثلاث فئات:
1. **بيانات الإنتاج الإلزامية (Production Seed):** تشمل تهيئة حساب المسؤول (البريد المستهدف)، تصنيفات المشاريع، والمحتوى الأساسي لخبرات العمل ثنائية اللغة لـ Amazon و Grammarly لضمان تشغيل الموقع في الطرح الأول (Phase 1).
2. **بيانات التطوير التجريبية (Development/Staging Seed):** تشمل مقالات مدونة افتراضية، ومحاكاة لسجلات المحادثات والتقييمات، وذلك لتسهيل اختبار لوحة المراقبة (Epic E2) محلياً دون الحاجة لطلب محادثات حقيقية مكلفة.

## 2. Prisma Seed Script Structure

يتم تشغيل سيناريو زرع البيانات تلقائياً عند تنفيذ أمر التهيئة في Prisma:

```typescript
// src/frontend/prisma/seed.ts
import { PrismaClient } from '@prisma/client';
const prisma = new PrismaClient();

async function main() {
  console.log("Starting seed database...");

  // 1. Seed Whitelisted Admin User
  const admin = await prisma.user.upsert({
    where: { email: 'owner@bashar.ai' },
    update: {},
    create: {
      email: 'owner@bashar.ai',
      name: 'Bashar',
      role: 'ADMIN',
    },
  });
  console.log("Admin user seeded:", admin.email);

  // 2. Seed Base Experiences (NDA-safe Amazon/Grammarly)
  await seedExperiences();

  // 3. Seed Base Project Outlines
  await seedProjects();

  console.log("Database seed completed successfully.");
}

main()
  .catch((e) => {
    console.error("Error during seeding:", e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

## 3. Whitelist & Admin User Seed

- **هدف الأمان:** يمنع Prisma seed إنشاء كلمات مرور افتراضية. يكتفي بتهيئة سجل مستخدم خامل بالبريد الإلكتروني المسموح به (`owner@bashar.ai`).
- **تفعيل الحساب:** عند قيام المطور بتسجيل الدخول لأول مرة عبر Google OAuth باستخدام نفس البريد الإلكتروني، يتعرف عليه النظام تلقائياً ويربط حساب الـ OAuth بالسجل المهيأ مسبقاً، مما يمنحه صلاحيات المسؤول (`ADMIN`) فوراً وبشكل مؤمن.

## 4. Bilingual Base Experience Seed (Amazon & Grammarly)

وفقاً لمتطلبات الـ PRD §8 Epic D1، يُشحن الموقع فورياً بدراسات حالة خبرة العمل (NDA-safe) خالية من الفراغات لضمان الجدارة والمصداقية من اليوم الأول.


## 5. RAG Ingestion Base Documents Seed

لتهيئة مساعد الذكاء الاصطناعي RAG وتزويده بالمعلومات الأساسية للرد على استفسارات الزوار الأولى:
- يُشحن جدول `Document` وجدول `Chunk` بالمعلومات العامة للمرشح وسيرته الذاتية.
- يتم ذلك عن طريق استدعاء سكربت إدخال الوثائق (`ingest.ts`) محلياً والذي يقرأ ملفات السيرة الذاتية الأساسية في مجلد `content/` ويقوم بتوليد التضمينات (Embeddings) المتجهية عبر OpenAI وحفظها في قاعدة البيانات قبل إطلاق النسخة الأولى.
