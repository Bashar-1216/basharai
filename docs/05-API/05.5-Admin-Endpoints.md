## 1. Observability Aggregated Metrics

يسحب هذا المنفذ البيانات التحليلية المجمعة (Costs, Latency, API Tokens) لتغذية لوحة المراقبة التفاعلية (Epic E2).

- **الرابط (Route):** `GET /api/v1/admin/metrics`
- **نوع الطلب (HTTP Method):** `GET`
- **التحقق (Authorization):** يتطلب رمز JWT للمسؤول (Bearer Token).
- **معاملات الاستعلام (Query Parameters):**
  - `range` -> النطاق الزمني: `7d` (7 أيام)، `30d` (30 يومًا)، أو `all`.

### 1.1 استجابة ناجحة (Success Response):
- **حالة الرد:** `200 OK`
- **جسم الاستجابة:**
```json
{
  "success": true,
  "data": {
    "summary": {
      "totalRequests": 1420,
      "totalCostUSD": 2.62,
      "averageLatencyMS": 1150,
      "averageEvalScore": 0.91
    },
    "charts": {
      "costsOverTime": [
        { "date": "2026-07-01", "cost": 0.35, "requests": 180 },
        { "date": "2026-07-02", "cost": 0.42, "requests": 210 }
      ],
      "latencyDistribution": {
        "p50": 980,
        "p95": 1450,
        "p99": 2100
      }
    }
  },
  "meta": {
    "timestamp": "2026-07-06T12:17:09Z",
    "requestId": "req-90b1c10d"
  }
}
```

## 2. Detail Logs Query List

للبحث والتدقيق في تفاصيل أسئلة وإجابات الزوار ومخرجات RAG بالتفصيل.

- **الرابط (Route):** `GET /api/v1/admin/logs`
- **نوع الطلب (HTTP Method):** `GET`
- **التحقق (Authorization):** يتطلب رمز JWT للمسؤول (Bearer Token).
- **معاملات الاستعلام (Query Parameters):**
  - `page` -> رقم الصفحة (الافتراضي: 1).
  - `limit` -> عدد السجلات لكل صفحة (الافتراضي: 20).
  - `language` -> تصفية باللغة: `en` أو `ar`.
  - `passed` -> تصفية بالنجاح في التقييم: `true` أو `false`.

### 2.1 استجابة ناجحة (Success Response):
- **حالة الرد:** `200 OK`
- **جسم الاستجابة:**
```json
{
  "success": true,
  "data": {
    "logs": [
      {
        "id": "log-uuid-v4-abc123",
        "queryText": "What projects did you build?",
        "responseText": "I have built several AI projects including...",
        "latencyMs": 1050,
        "costUsd": 0.0012,
        "languageCode": "en",
        "createdAt": "2026-07-06T11:45:00Z",
        "evalPassed": true
      }
    ],
    "pagination": {
      "currentPage": 1,
      "totalPages": 5,
      "totalItems": 98
    }
  },
  "meta": {
    "timestamp": "2026-07-06T12:17:09Z",
    "requestId": "req-90b1c11e"
  }
}
```

## 3. Vector Ingestion Manual Trigger

يسمح للمسؤول بإجبار النظام على مراجعة ملفات MDX وتحديث قاعدة البيانات المتجهية pgvector محلياً.

- **الرابط (Route):** `POST /api/v1/admin/ingest`
- **نوع الطلب (HTTP Method):** `POST`
- **التحقق (Authorization):** يتطلب رمز JWT للمسؤول (Bearer Token).

### 3.1 استجابة ناجحة (Success Response):
- **حالة الرد:** `202 Accepted`
- **جسم الاستجابة:**
```json
{
  "success": true,
  "data": {
    "message": "Manual vector store ingestion triggered. Files are being parsed and embedded.",
    "status": "PROCESSING"
  },
  "meta": {
    "timestamp": "2026-07-06T12:17:09Z",
    "requestId": "req-90b1c12f"
  }
}
```
