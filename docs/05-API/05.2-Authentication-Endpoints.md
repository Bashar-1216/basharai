## 1. OAuth Sign-in Entry Point

يبدأ هذا المنفذ عملية مصادقة المسؤول ويوجهه لصفحة الموافقة الخاصة بمزود الخدمة المختار (Google أو GitHub).

- **الرابط (Route):** `GET /api/auth/signin/:provider`
- **المعاملات (Parameters):**
  - `:provider` -> `google` أو `github`
- **نوع الطلب (HTTP Method):** `GET`
- **الاستجابة المتوقعة (Response):**
  - تحويل الزائر (HTTP 302 Redirect) إلى رابط تسجيل الدخول لمزود OAuth مع تضمين معرف العميل (Client ID) ونطاق الصلاحيات المطلوب (Scope: email, profile).

## 2. OAuth Callback Receiver

يستقبل هذا المنفذ الرمز الممرر من مزود OAuth بعد نجاح تسجيل الدخول لتوليد جلسة المسؤول والتأكد من القائمة البيضاء.

- **الرابط (Route):** `GET /api/auth/callback/:provider`
- **نوع الطلب (HTTP Method):** `GET`
- **معاملات الاستعلام (Query Parameters):**
  - `code` -> الرمز المؤقت الممرر من المزود لاستبداله بـ token.
  - `state` -> رمز التحقق العشوائي لمنع هجمات CSRF.

### 2.1 سيناريو نجاح التحقق (Success Response):
- **حالة الرد (Status):** `302 Found`
- **رأس الطلب (Headers):**
  - `Set-Cookie: __Secure-next-auth.session-token=<JWT_TOKEN>; HttpOnly; Secure; SameSite=Lax; Path=/`
  - `Location: /admin` (تحويل المستخدم للوحة التحكم).

### 2.2 سيناريو رفض الهوية - غير مدرج بالقائمة البيضاء (Failed Response):
- **حالة الرد (Status):** `302 Found`
- **رأس الطلب (Headers):**
  - `Location: /auth/error?reason=AccessDenied` (تحويل لصفحة رفض الدخول).

## 3. Get Active Session Status

يستخدمه تطبيق المتصفح لمعرفة ما إذا كان المستخدم مسجلاً كمسؤول حالياً وجلب معلوماته العامة.

- **الرابط (Route):** `GET /api/auth/session`
- **نوع الطلب (HTTP Method):** `GET`

### 3.1 استجابة مستخدم مسجل (Authenticated Response):
- **حالة الرد (Status):** `200 OK`
- **جسم الاستجابة (Response Body):**
```json
{
  "success": true,
  "data": {
    "user": {
      "name": "Bashar",
      "email": "owner@bashar.ai",
      "image": "https://lh3.googleusercontent.com/a/...",
      "role": "ADMIN"
    },
    "expires": "2026-08-06T12:16:30.000Z"
  },
  "meta": {
    "timestamp": "2026-07-06T12:16:30Z",
    "requestId": "req-90b1c03e"
  }
}
```

### 3.2 استجابة مستخدم غير مسجل (Unauthenticated Response):
- **حالة الرد (Status):** `200 OK`
- **جسم الاستجابة (Response Body):**
```json
{
  "success": true,
  "data": null,
  "meta": {
    "timestamp": "2026-07-06T12:16:30Z",
    "requestId": "req-90b1c03e"
  }
}
```

## 4. Admin Sign-out

يقوم بتعطيل وحذف جلسة المسؤول الحالية من المتصفح والذاكرة المؤقتة.

- **الرابط (Route):** `POST /api/auth/signout`
- **نوع الطلب (HTTP Method):** `POST`
- **الاستجابة المتوقعة (Response):**
  - **حالة الرد (Status):** `200 OK`
  - **جسم الاستجابة (Response Body):**
```json
{
  "success": true,
  "data": {
    "message": "Successfully signed out."
  },
  "meta": {
    "timestamp": "2026-07-06T12:16:30Z",
    "requestId": "req-90b1c04f"
  }
}
```
  - **حذف الكوكيز (Headers):**
    - `Set-Cookie: __Secure-next-auth.session-token=; Max-Age=0; Path=/`

## 5. Emergency Passwordless Magic Link

يستخدم كحالة تراجع طارئة لإرسال رابط تسجيل دخول لبريد المسؤول دون الحاجة لمزود OAuth.

- **الرابط (Route):** `POST /api/auth/magic-link`
- **نوع الطلب (HTTP Method):** `POST`
- **جسم الطلب (Request Body):**
```json
{
  "email": "owner@bashar.ai"
}
```

### 5.1 استجابة ناجحة (Success Response):
- **حالة الرد (Status):** `200 OK`
- **جسم الاستجابة (Response Body):**
```json
{
  "success": true,
  "data": {
    "message": "If the email is whitelisted, a login link has been sent."
  },
  "meta": {
    "timestamp": "2026-07-06T12:16:30Z",
    "requestId": "req-90b1c05a"
  }
}
```
*ملاحظة أمنية:* نرجع نفس الرسالة الناجحة دائماً حتى لو كان البريد غير مسجل بالقائمة البيضاء، لمنع المخترقين من تخمين العناوين المسجلة (Email Enumeration protection).
