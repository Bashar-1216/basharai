## 1. API Design Principles

يعتمد تصميم واجهات برمجة التطبيقات (APIs) في منصة bashar.ai على مبادئ **RESTful API** المعيارية لضمان البساطة والمرونة والتوافق مع بيئة التطوير ثنائية الخدمات (Next.js + FastAPI).

### المبادئ المتبعة:
- **التوجيه المعتمد على الموارد (Resource-Oriented):** تصميم الروابط بناءً على الأسماء (Noun resources) مثل `/api/v1/projects` وليس الأفعال `/api/v1/getProjects`.
- **التمثيل المعياري للعمليات (Standard HTTP Verbs):**
  - `GET`: لقراءة البيانات (خالٍ من التأثيرات الجانبية - Idempotent).
  - `POST`: لإنشاء موارد جديدة (مثل إرسال سؤال للمساعد أو إرسال تقييم).
  - `PUT`/`PATCH`: لتحديث موارد قائمة (لوحة التحكم).
  - `DELETE`: لحذف موارد (إيقاف محادثة أو حذف تدوينة).
- **اللاصفية (Statelessness):** لا يحتفظ خادم FastAPI بأي حالة جلسة للمتصفح. تعتمد المصادقة على رموز JWT الممررة مع كل طلب.

## 2. Versioning & Base URLs

نستخدم نظام **إصدار الروابط (URI Versioning)** لتجنب تعطل تطبيقات الويب عند ترقية واجهات الخدمات الخلفية.

### 2.1 الروابط الأساسية (Base URLs):

1. **الواجهة الأمامية والوسيط البيني (Next.js BFF):**
   - الرابط: `https://bashar.ai/api/`
   - الوظيفة: معالجة مصادقة NextAuth.js وطلب صفحات المحتوى الثابت وعمل كـ Reverse Proxy إلى FastAPI.
2. **الواجهة الخلفية للذكاء الاصطناعي (FastAPI Engine):**
   - الرابط: `https://api.bashar.ai/api/v1/`
   - الوظيفة: معالجة طلبات الـ RAG، والتقييم التلقائي، والإحصائيات التحليلية.

## 3. Naming Conventions & JSON Formatting

لضمان نظافة الاتصالات وراحة المطورين في البيئتين (Javascript و Python):

- **روابط المسار (Paths):** تكتب بأسلوب **kebab-case** (أحرف صغيرة مفصولة بشرطة) مثل `/api/v1/blog-posts`.
- **معاملات الاستعلام (Query Parameters):** تكتب بأسلوب **camelCase** مثل `/api/v1/projects?isFeatured=true`.
- **مفاتيح الـ JSON (JSON Keys):**
  - **الواجهة الأمامية (Javascript) تتوقع:** `camelCase` (مثل `publishedAt`).
  - **الواجهة الخلفية (Python) تكتب داخلياً بـ:** `snake_case` (مثل `published_at`).
  - **الحل:** نستخدم واجهات تحويل تلقائية (Pydantic configuration Aliases) في FastAPI لتصدير واستقبال الـ JSON بأسلوب `camelCase` مع الحفاظ على نظافة كود Python داخلياً.

## 4. Request & Response Headers

تتضمن كافة طلبات الاستعلام والاستجابة الرؤوس (Headers) التالية لضمان الأمان والتدويل:

| Header Name | Type | Value Example | Description |
|-------------|------|---------------|-------------|
| `Content-Type` | Request/Response | `application/json` | Type of data payload. |
| `Accept-Language` | Request | `ar` or `en` | Preferred language for error messages and dynamic metadata. |
| `Authorization` | Request | `Bearer <JWT_TOKEN>` | NextAuth.js signed JWE token for admin authorization. |
| `X-Internal-Key` | Request | `secure-internal-secret` | Internal BFF shared token to authenticate proxy requests. |
| `X-Correlation-ID` | Response | `req-50b14c3e` | Unique request identifier for structured log tracking. |

## 5. Standard Envelope Pattern

تتبع جميع استجابات الـ API (باستثناء SSE streams) نمط **الغلاف الموحد (Standard Envelope Pattern)** لسهولة القراءة والمعالجة البرمجية:

### 5.1 استجابة ناجحة (Success Payload Envelope):
```json
{
  "success": true,
  "data": {
    "id": "project-uuid-v4",
    "title": "Bilingual RAG Assistant"
  },
  "meta": {
    "timestamp": "2026-07-06T12:16:06Z",
    "requestId": "req-50b14c3e"
  }
}
```

### 5.2 استجابة فشل (Error Payload Envelope):
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_FAILED",
    "message_en": "The provided email address is invalid.",
    "message_ar": "عنوان البريد الإلكتروني المدخل غير صالح.",
    "correlation_id": "req-50b14c3e"
  }
}
```

## 6. Accept-Language Processing

يتحكم الرأس `Accept-Language` في لغة البيانات المسترجعة ورسائل الأخطاء:
- إذا كانت القيمة `ar` (أو تبدأ بـ `ar-`) -> يقوم خادم FastAPI بإرجاع الأوصاف والمخرجات المترجمة للغة العربية مع صياغة الأخطاء بالعربية.
- إذا كانت القيمة `en` أو غير ذلك -> يتراجع الخادم تلقائياً للغة الإنجليزية كخيار افتراضي (Fallback).

## 7. Cross-Origin Resource Sharing (CORS) Policy

نطبق سياسة CORS صارمة في خادم FastAPI لمنع استدعاء البيانات من نطاقات مجهولة:
- **المواقع المسموحة (Allowed Origins):**
  - في التطوير المحلي: `http://localhost:3000` (Next.js client).
  - في الإنتاج: `https://bashar.ai`.
- **العمليات المصرح بها (Allowed Methods):**
  - `GET`, `POST`, `OPTIONS` للزوار.
  - `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS` للمسؤول المسجل.
- **تأمين ملفات التعريف (Credentials):**
  - تفعيل `allow_credentials=True` لتمكين فحص الكوكيز المؤمنة في طلبات المسؤولين.
