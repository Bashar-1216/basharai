## 1. AI RAG Chat Endpoint (Streaming SSE)

يستقبل هذا المنفذ أسئلة الزوار ويقوم بتشغيل مسار RAG لإرجاع إجابة متدفقة في زمن حقيقي.

- **الرابط (Route):** `POST /api/v1/chat`
- **نوع الطلب (HTTP Method):** `POST`
- **نوع المحتوى (Headers):** `Content-Type: application/json`
- **جسم الطلب (Request Body):**
```json
{
  "message": "ما هي لغات البرمجة التي تتقنها؟",
  "sessionId": "usr_fp_80f14c2b9a",
  "history": [
    {
      "role": "user",
      "content": "مرحباً"
    },
    {
      "role": "assistant",
      "content": "أهلاً بك! كيف يمكنني مساعدتك اليوم؟"
    }
  ]
}
```

### 1.1 استجابة البث المباشر (Streaming Response):
- **حالة الرد:** `200 OK`
- **رأس الاستجابة (Headers):**
  - `Content-Type: text/event-stream`
  - `Cache-Control: no-cache`
  - `Connection: keep-alive`

- **تدفق البيانات (SSE Chunks Payload):**
  يرسل الخادم البيانات تدريجياً كأحداث مفرّقة تبدأ بـ `data:` وتنتهي بـ `\n\n`:
  ```
  data: {"chunk": "أتقن"}
  
  data: {"chunk": " لغة"}
  
  data: {"chunk": " Python"}
  
  data: {"chunk": " و"}
  
  data: {"chunk": " TypeScript."}
  
  data: [DONE]
  ```
- **حالة الخطأ (في حال التجاوز أو المشاكل):**
  إذا تم رفض الطلب (مثال: Rate Limit)، يرجع خطأ JSON قياسي:
  ```json
  {
    "success": false,
    "error": {
      "code": "CHAT_RATE_LIMITED",
      "message_en": "Too many requests. Please try again in 45 seconds.",
      "message_ar": "طلبات كثيرة جداً. يرجى المحاولة بعد 45 ثانية."
    }
  }
  ```

## 2. Trigger Manual Evaluation Run

يسمح للمسؤول بإطلاق اختبار جودة يدوي لتشغيل الأسئلة الذهبية وتقييم أداء RAG.

- **الرابط (Route):** `POST /api/v1/eval`
- **نوع الطلب (HTTP Method):** `POST`
- **التحقق (Authorization):** يتطلب رمز JWT للمسؤول (Bearer Token).
- **الاستجابة الناجحة (Success Response):**
  - **حالة الرد:** `202 Accepted` (يتم تشغيل التقييم خلف الكواليس كأمر غير متزامن).
  - **جسم الاستجابة:**
```json
{
  "success": true,
  "data": {
    "runId": "eval-run-uuid-v4-9988",
    "status": "PROCESSING",
    "totalQuestions": 25,
    "estimatedDurationSeconds": 45
  },
  "meta": {
    "timestamp": "2026-07-06T12:16:55Z",
    "requestId": "req-90b1c08a"
  }
}
```

## 3. Get Evaluation Batch Results

جلب نتائج تقييم محددة لمعرفة دقة RAG ومقارنتها عبر لوحة المراقبة.

- **الرابط (Route):** `GET /api/v1/eval/:runId`
- **نوع الطلب (HTTP Method):** `GET`
- **التحقق (Authorization):** يتطلب رمز JWT للمسؤول (Bearer Token).

### 3.1 استجابة ناجحة (Success Response):
- **حالة الرد:** `200 OK`
- **جسم الاستجابة:**
```json
{
  "success": true,
  "data": {
    "runId": "eval-run-uuid-v4-9988",
    "status": "COMPLETED",
    "completedAt": "2026-07-06T12:17:40Z",
    "metrics": {
      "averageContextRelevance": 0.92,
      "averageGroundedness": 0.88,
      "averageAnswerRelevance": 0.95,
      "passRate": 0.90
    },
    "results": [
      {
        "question": "ما هي أدوارك في جرامرلي؟",
        "expectedAnswer": "مهندس برمجيات لمنصة الذكاء الاصطناعي",
        "generatedAnswer": "عملت كمهندس برمجيات لتطوير منصة الذكاء الاصطناعي...",
        "scores": {
          "contextRelevance": 1.0,
          "groundedness": 0.9,

    ]
  },

```
