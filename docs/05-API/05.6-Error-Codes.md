## 1. Bilingual Error Envelope Strategy

لتسهيل معالجة الأخطاء من قبل مطوري الواجهة الأمامية وتقديم رسائل ذات معنى للمستخدمين في دول الخليج (عربي) والعالم (إنجليزي)، تتبع جميع الأخطاء الصادرة عن Next.js BFF أو خادم FastAPI الهيكل الموحد التالي:

```json
{
  "success": false,
  "error": {
    "code": "CHAT_RATE_LIMITED",
    "message_en": "You have exceeded the rate limit. Please try again after {retry_after} seconds.",
    "message_ar": "لقد تجاوزت الحد المسموح به للطلبات. يرجى المحاولة بعد {retry_after} ثانية.",
    "retry_after": 45,
    "correlation_id": "err_req_50b12c"
  }
}
```

## 2. Global Error Codes Taxonomy | جدول تصنيفات الأخطاء

| Error Code | HTTP Status | English Default Message | Arabic Default Message |
|------------|-------------|-------------------------|------------------------|
| **AUTH_UNAUTHORIZED** | 401 | Access denied. Please sign in to continue. | الوصول مرفوض. يرجى تسجيل الدخول للمتابعة. |
| **AUTH_FORBIDDEN** | 403 | You do not have permission to access this resource. | ليس لديك صلاحية للوصول إلى هذا المورد. |
| **VALIDATION_FAILED** | 422 | Input validation failed. Please check your data. | فشل التحقق من البيانات المدخلة. يرجى التحقق من المدخلات. |
| **CHAT_RATE_LIMITED** | 429 | Too many requests. Please slow down. | طلبات كثيرة جداً. يرجى المحاولة بعد قليل. |
| **LLM_API_TIMEOUT** | 504 | AI service took too long to respond. Please try again. | استغرق خادم الذكاء الاصطناعي وقتاً طويلاً للرد. يرجى المحاولة. |
| **RAG_CONTEXT_FAIL** | 500 | Database failed to retrieve search context. | فشل محرك البحث المتجهي في جلب السياق. |
| **RESOURCE_NOT_FOUND**| 404 | The requested item could not be found. | المورد المطلوب غير موجود. |
| **INTERNAL_SYSTEM_ERR**| 500 | An unexpected error occurred. | حدث خطأ داخلي في النظام. |

## 3. Client Handling & Fallback UI Integration

عند استقبال الواجهة الأمامية (Browser client) لخطأ من الـ API:

1. **التعرف التلقائي على اللغة (RSC Locale Detection):**
   - يقرأ المتصفح مسار اللغة الحالي (`/ar/` أو `/en/`).
   - يعرض الرسالة المقابلة `message_ar` أو `message_en` تلقائياً لتجنب الترجمة اليدوية غير الدقيقة في المتصفح.
2. **استخدام الـ Correlation ID:**
   - يتم عرض الـ `correlation_id` بشكل صغير أسفل الرسالة للزائر ليقوم بتقديمه للمسؤول في حال تعذر حل المشكلة يدوياً، مما يسهل عملية تقصي الأخطاء في سجلات PostgreSQL.
