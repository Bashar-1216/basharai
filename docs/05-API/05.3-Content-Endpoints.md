## 1. Public Content Retrieval Endpoints

هذه الواجهات مفتوحة للجميع (Public) وتستخدم لجلب بيانات السيرة الذاتية والمشاريع والمدونة لعرضها في المتصفح.

- **قائمة المشاريع (List Projects):**
  - `GET /api/v1/projects` -> جلب قائمة المشاريع المميزة والعادية.
  - معاملات الاستعلام: `?isFeatured=true` (لتصفية المشاريع الرائدة فقط).
- **تفاصيل المشروع (Get Project Detail):**
  - `GET /api/v1/projects/:slug` -> جلب تفاصيل مشروع معين ومحتوى الـ MDX الخاص به.
- **قائمة الخبرات المهنية (List Experiences):**
  - `GET /api/v1/experience` -> جلب بيانات خبرات العمل (Amazon & Grammarly) لزرعها في صفحة التايم لاين.
- **تدوينات المدونة (List Blog Posts):**
  - `GET /api/v1/blog` -> جلب قائمة التدوينات المنشورة.
- **تفاصيل التدوينة (Get Blog Post Detail):**
  - `GET /api/v1/blog/:slug` -> جلب المقال بالكامل للقراءة.

## 2. Admin Content Mutation Endpoints (CRUD)

تتطلب هذه الواجهات **مصادقة المسؤول إجبارياً** وتمرير رمز JWT صالح في رأس الطلب.

- **إدارة المشاريع (Projects CRUD):**
  - `POST /api/v1/projects` -> إنشاء مشروع جديد.
  - `PUT /api/v1/projects/:slug` -> تحديث تفاصيل مشروع قائم.
  - `DELETE /api/v1/projects/:slug` -> حذف مشروع.
- **إدارة تدوينات المدونة (Blog CRUD):**
  - `POST /api/v1/blog` -> إنشاء مقال جديد.
  - `PUT /api/v1/blog/:slug` -> تعديل مقال أو تغيير حالة النشر (`published` -> true/false).
  - `DELETE /api/v1/blog/:slug` -> حذف مقال.

## 3. Payload Specifications | مواصفات حزم البيانات

### 3.1 جلب تفاصيل مشروع (GET `/api/v1/projects/rag-assistant`):
- **حالة الرد:** `200 OK`
- **جسم الاستجابة (Response Body):**
```json
{
  "success": true,
  "data": {
    "id": "uuid-v4-proj-1",
    "slug": "rag-assistant",
    "title": {
      "en": "Bilingual RAG Assistant",
      "ar": "مساعد RAG ثنائي اللغة"
    },
    "description": {
      "en": "A highly-optimized RAG system with pgvector...",
      "ar": "نظام توليد معزز بالاسترجاع متطور مع pgvector..."
    },
    "githubUrl": "https://github.com/...",
    "liveUrl": "https://bashar.ai",
    "publishedAt": "2026-07-06T12:00:00Z",
    "featured": true
  },
  "meta": {
    "timestamp": "2026-07-06T12:16:42Z",
    "requestId": "req-90b1c06d"
  }
}
```

```json
  "descriptionEn": "Updated description text here...",

  "featured": true

```
- **حالة الرد الناجح:** `200 OK`
