## 1. System Overview

يصف مستند **التصميم العام للنظام (High-Level Architecture)** الهيكل البنيوي الكلي لمنصة bashar.ai والروابط التقنية بين مختلف الأنظمة والمكونات. 

يعتمد النظام على نمط **Decoupled Client-Server Monorepo** مع فصل طبقة العرض الأمامية (Frontend & BFF) المبنية بـ Next.js عن طبقة الحوسبة والذكاء الاصطناعي الخلفية (AI Backend Engine) المبنية بـ FastAPI، وذلك لضمان سرعة تصفح المحتوى الثابت وعزل عمليات RAG المكلفة وتسهيل مراقبتها.

## 3. Architectural Layers | طبقات النظام

### 3.1 طبقة المستخدم (Client Layer)
- **المكونات:** المتصفح الخاص بالزائر (هاتف ذكي، جهاز لوحي، حاسب شخصي).
- **الوظيفة:** عرض واجهات HTML/CSS المستجيبة، التعامل مع مدخلات المستخدم، بث المحادثة في زمن حقيقي، وتحديث اتجاه النصوص (LTR/RTL) بناءً على مسار اللغة المختار.

### 3.2 طبقة الواجهة الأمامية ووسيط البيانات (Frontend & BFF Layer)
- **Next.js 15 Server:** يعمل كخادم ويب يقوم بالتوليد المسبق للصفحات الثابتة (SSG/ISR) لركائز المحتوى (خبرة العمل، المشاريع، المدونة) لتحقيق تحميل فوري.
- **BFF (Backend for Frontend):** تعمل كبوابة أمنية (Gateway) لمعالجة الطلبات القادمة من المتصفح والتحقق من صلاحياتها (Auth/Rate-limiting) قبل تحويلها إلى خادم FastAPI الخلفي.
- **Git-based MDX Content:** نظام التخزين المحلي للملفات النصية المشفرة المعتمدة على Git لضمان صفر تكلفة تشغيلية واستقرار كامل للصفحات الرئيسية.

### 3.3 طبقة الذكاء الاصطناعي الخلفية (AI Core Backend Layer)
- **FastAPI Application:** خادم تطبيقات مخصص لمعالجة طلبات الذكاء الاصطناعي الثقيلة وعمليات الحوسبة الحية. يتميز بدعمه الكامل للعمليات غير المتزامنة (Async) والبث المباشر.
- **LangChain Pipeline:** محرك تنظيم منطق الـ RAG، ويشمل ذلك كشف لغة الاستعلام، بناء الموجهات، الاتصال بمحرك التضمين، واستدعاء نموذج GPT-4o.
- **Evaluation Engine:** كود معزول مخصص لتشغيل اختبارات التقييم اليدوية والتلقائية لخط الأنابيب لتسجيل مستويات الدقة والأداء في قاعدة البيانات.

### 3.4 طبقة البيانات والذاكرة المؤقتة (Data & Storage Layer)
- **PostgreSQL 16 (Neon/Supabase):** قاعدة البيانات الأساسية لتخزين تحليلات الموقع، جلسات المسؤول، وسجلات جودة RAG، بالإضافة لبيانات التقييم.
- **pgvector Extension:** مخزن متجهات التضمين المتكامل مع الجداول العادية لتسريع استدعاء البيانات الدلالية وحساب المسافات الحسابية (Cosine distance) بأقل تكلفة ممكنة.
- **Redis (Upstash):** ذاكرة وصول عشوائي مؤقتة فائقة السرعة تستخدم لحفظ عدادات Rate Limiting للمستخدمين وتخزين الجلسات الموقعة مؤقتاً ومحاذاة الطلبات المتكررة.

## 4. Interfaces & Communication Protocols | بروتوكولات الاتصال

نؤمن وتوحد كافة الاتصالات بين الطبقات والخدمات بالبروتوكولات المعيارية التالية:

| Source | Destination | Protocol | Payload Type | Authentication |
|--------|-------------|----------|--------------|----------------|
| **Browser** | **Next.js BFF** | HTTPS (TLS 1.3) | HTML, JSON | Session Cookie (Secure, HttpOnly) |
| **Browser** | **Next.js BFF (Chat)**| SSE (Server-Sent Events) | Text Stream | None / Client Fingerprint |
| **Next.js BFF** | **FastAPI Backend** | HTTP/1.1 | JSON | Bearer JWT / Internal Shared Key |
| **FastAPI Backend** | **OpenAI API** | HTTPS | JSON / Stream | API key (Secured Env Var) |
| **Next.js / FastAPI** | **PostgreSQL** | TCP (Postgres Protocol) | SQL Queries | TLS Connection String |
| **FastAPI** | **Redis** | TCP (Redis Protocol) | Key-Value Command | Password Auth |

## 5. Traceability Matrix | مطابقة القرارات مع العمارة التقنية

توضح هذه المصفوفة كيفية تلبية التصميم العام لمتطلبات وثائق العمارة المنجزة (Phase 02):

- **تنفيذ 02.1 Tech Stack:**
  - يوضح الرسم بوضوح فصل FastAPI عن Next.js واستخدام PostgreSQL كقاعدة بيانات موحدة تحوي pgvector.
- **تنفيذ 02.2 Infrastructure:**
  - تمثيل خوادم Vercel للواجهة الأمامية وRailway لخادم FastAPI وسحابة Supabase/Neon لقاعدة البيانات وتوضيح تكامل CDN Edge.
- **تنفيذ 02.3 Authentication:**
  - إظهار دور NextAuth.js في التحقق من تسجيل دخول المسؤول وتخزين الجلسات في Redis لتأمين الواجهة الخلفية FastAPI عبر Bearer tokens.
- **تنفيذ 02.5 RAG Architecture:**
  - توضيح مسار الطلب واسترجاع القطع الدلالية من PgVector وتمريرها لمحرك LangChain للاتصال بـ OpenAI.
- **تنفيذ 02.6 Logging & Monitoring:**
  - إظهار اتصال خادم FastAPI بقاعدة البيانات لتسجيل بيانات الأداء ومحاذاة التتبع التلقائي بـ LangSmith.
